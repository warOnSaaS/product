# warOnSaaS product

The open-source suite that replaces rented business software: one web app and one phone app (iPhone and Android), built from shared modules.

Nothing is built yet. Every change to this repository is made by the wOS GitHub App after qualification; pull requests are not opened by hand. See https://waronsaas.com and https://github.com/warOnSaaS/wos.
